# demos

- [`autokernel-hexagon/`](autokernel-hexagon/README.md) — AutoKernel-style Triton kernel optimization loop for the Qualcomm Hexagon NPU (Hexagon-MLIR backend), starting with FP16 RMSNorm on HVX.
- [`npu-autokernel/`](npu-autokernel/README.md) — vendor-neutral, multi-backend NPU auto-optimization layer (adapter bundles + capability manifests + fixed evaluator), first workload DeiT-tiny, first backend Hexagon-MLIR. Preparation stage (A0–A4).
